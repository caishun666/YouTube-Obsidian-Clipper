Chrome 扩展设置

YouTube → Obsidian Clipper

从当前打开的 YouTube 视频页面抓取标题、简介、章节、字幕与评论， 经 Local REST API 写入 Obsidian 笔记库。

Obsidian Local REST API

安装社区插件 Local REST API，在插件设置中复制 API Key。 推荐启用 HTTP Server（默认 http://127.0.0.1:27123）， 避免 Chrome 拦截自签 HTTPS 证书。

笔记目录与命名

可用变量： {{title}} {{videoId}} {{channel}} {{date}} {{datetime}} {{views}} {{duration}} {{published}} {{seq}} {{seq2}} {{seq:N}}

序号按目标目录内已有笔记自动递增。写成 视频-{{seq2}} 得到 视频-01、视频-02； {{seq}} 为不补零（1、2、3）， {{seq:3}} 为 001。

其他示例：{{date}} - {{title}}、{{channel}}-{{seq2}}-{{title}}

封面命名可用同上变量。示例： {{videoId}}-cover → abc123-cover.jpg； {{seq2}}-{{title}} → 01-标题.jpg （扩展名自动按图片格式补）。

抓取内容

字段说明

  • 标题 / 链接 / 播放量 / 发布日期：从页面数据与 DOM 读取
  • 视频封面：下载图片写入附件目录，并在笔记中用 ![[...]] 嵌入
  • 视频标签：页面 keywords + 简介 hashtag
  • 章节：时间戳章节 + 可选章节缩略图
  • 转录：点击页面「显示文稿」后从 DOM 提取；无字幕时为空
  • 评论：滚动评论区加载，按热度取前 N 条；每条主题（含折叠回复）算一条
  • 视频本体：暂不自动下载，请手动保存后自行链接
